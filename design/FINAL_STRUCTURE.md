## Mapping back to milestones

| Milestone | Where it lives |
|---|---|
| M1 Concept | `BACKEND_PLAN.md`, `design/HLD.md` |
| M2 Backend setup | `server/src/main/java/com/learnify/*` |
| M3 Frontend setup | `client/` |
| M4 Auth0 | `server/.../security/`, `client/hooks/useAuth.js` |
| M5 DB schema | `server/.../entity/`, `server/.../repository/`, `db/migration/` |
| M6 Lesson rendering | `client/components/LessonRenderer.jsx` + `blocks/` |
| M7 Routing/sidebar | `client/App.jsx`, `client/components/SidebarNavigation.jsx` |
| M8 AI prompt design | `server/.../ai/`, `server/resources/prompts/` |
| M9 YouTube | `server/.../integration/youtube/` |
| M10 Multilingual TTS | `server/.../integration/gemini/` |
| M11 PDF export | `client/components/DownloadButton.jsx` (+ `design/components/10-pdf-export.md`) |
| M12 Hosting/CI-CD | `.github/workflows/`, Render + Vercel dashboards (no repo folder) |
| M13 Showcase/docs | `README.md` at repo root (not yet created) |

Nothing from the roadmap is unaccounted for.
